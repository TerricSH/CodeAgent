# ask_user

当你需要补充信息才能继续时，向用户提问。支持一次提出多个问题，逐个收集后统一打包返回。

## 规则

- 仅在确有信息缺口、且无法自行从上下文/工具获取时使用，不要用来确认显而易见的事
- 一次调用可在 `questions` 里放多个问题，避免反复打断用户
- 每个问题可提供 `options` 让用户快速选择；用户也能给出自己的意见（除非 `allow_freeform` 设为 false）
- 不提供 `options` 即为纯自由作答
- 该工具会阻塞等待用户作答；拿到答案后基于答案继续，不要重复追问已回答的内容
- 用户的回答会作为基础信息持续提供给你，无需反复询问相同问题
